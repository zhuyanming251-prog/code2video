# Frame design — The Last Clue (sketch pass, dual-track)

## Track A — White-mold / recipe props
3D still-life language: desk overhead, typewriter, knife, evidence bag + table leg, folder/markers kit.
Assets in `assets/visuals/props-*.png`, `prop-*.png`, `desk-overhead.png`.

## Track B — Retro crime DV
Grain + scanlines + color cast over apartment / interrogation / cork-board plates.
Assets: `dv-apartment.png`, `interrogation-room.png`, `cork-board.png`.

## Depth rules (anti-flat)
- Full-bleed photographic plate behind type
- Floating polaroids / prop shots with drop shadow
- Spotlight cone + vignette + film grain
- Red rings / caution tape / stamps as overlays only
- No pure text cards as the only content
